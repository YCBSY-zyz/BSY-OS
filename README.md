# BSY-OS
This is  a mini core  real-time operating system！A truly distinctive operating system. 

It has extremely low requirements for the size of Flash and RAM. 

IT can run on a microcontroller as small as the MEGA48PA，only  4K FLASH  and 512 Byte RAM. And it can run a simple LED project. 

It is simple and easy to use, and can be conveniently ported to other microcontroller platforms.
